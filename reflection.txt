In this module, I was able to build on Module 10 by introducing a Calculation model using SQLAlchemy and working with Pydantic validation. In the previous module, I had worked with the User model, but this assignment taught me how to structure database models for different types of data. I learned how to validate calculation inputs, restrict operation types, and prevent errors in edge cases such as division by zero before data reaches the database.

Since I already had a basic Python calculator from previous modules, I was able to reuse the existing arithmetic functions when implementing the factory pattern. Instead of writing separate logic for each calculation, the factory selects the appropriate operation and creates a Calculation object. This showed me how design patterns can make code more organized and easier to maintain.

In this module, I also wrote unit tests for the factory and validation schemas, along with integration tests to check if data storage and retrieval from Postgres is working. Even though we haven't implemented calculation API routes yet, testing the underlying logic helped ensure everything worked correctly.

The biggest challenge I faced was getting Docker to run properly and getting everything configured correctly in the yml file. After troubleshooting, I switched Python version because for some reason Python is crashing in the Docker image. This resolved the issue and allowed all integration tests to pass. This module made me a more rounded developer by helping me understand how database modeling, validation, testing, and CI/CD work together.
